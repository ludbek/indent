==================
A digit-led attribute name is reinterpreted as a positional number
followed by a separate attribute (known grammar limitation: the
digit run is greedily consumed as a number token before the letters
that follow it, so no syntax error surfaces at this layer -- the
hand-written indent-parser tokenizer rejects this input directly)
==================

org 1abc="x"

---

(document
  (statement
    type: (type)
    value: (positional_value (number))

      name: (attribute_name)
